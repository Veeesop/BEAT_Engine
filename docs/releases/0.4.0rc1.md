# BEAT Engine 0.4.0rc1

Qualification candidate for Deploy Level 2 solving with BEAT Metal on Apple
Silicon.

- Add Deploy fixed-source Level 2 Metal support: Metal operator assembly and
  field evaluation, host dense solve, and the established CPU near-face and
  ground-image correction path.
- Preserve CPU and CUDA Level 2 request behavior. Deploy Level 3 parity-ROM
  solves remain CPU/CUDA only; Metal is rejected explicitly.
- Preserve the existing worker protocol and request/result schemas.
- Pin BLAS to one thread in the standalone CPU reference-gate entry point so
  the exact interior-resonance regression is reproducible across CI hosts.

## Candidate qualification scope

Local source qualification passed on an Apple Silicon M1 with a functional
Metal device. The Deploy S218BP example package was tested at the nearest
exported frequency to 80 Hz (`79.31303405761719 Hz`) for baseline,
close-speaker, and ground-image cases. Relative complex-pressure L2 differences
from CPU were `2.6738081e-6`, `2.8575496e-6`, and `3.1598207e-6`; maximum SPL
deltas were `0.000040`, `0.000034`, and `0.000044 dB`. The close-speaker case
exercised 34,692 near-face pairs; the ground-image case exercised 16,556
ground-image near-face pairs. These results apply only to the listed package,
frequency, and scenes and do not establish general numerical accuracy.

The Metal host, lifecycle, desktop Level 2, and parity checks passed on the same
M1. A locally built candidate wheel was installed into a fresh Python 3.11
environment outside the checkout; Metal instantiation, paths, and doctor passed.
A separate fresh Deploy environment installed that wheel and passed the Metal
Level 2 smoke, lifecycle check, and the three listed parity cases. These are
local candidate artifacts and are not immutable published release assets. The
candidate still requires exact-commit Windows/Linux/macOS CI and a trusted
release-commit hardware workflow. CUDA GPU qualification is separate. This
candidate does not add a packaged macOS Deploy application, and Deploy Level 3
remains unavailable on Metal.

Final candidate tag/commit, wheel and source archive hashes, immutable artifact
URLs, exact-commit CI, doctor output, and hardware-test artifacts are pending
qualification. Do not replace or reuse an existing version or release asset.
